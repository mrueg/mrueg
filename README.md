## Great to see you here!

#### About Me

I'm Manuel, a Berlin-based engineer who has been contributing to Open Source for more than 15 years. Most of my work happens in Go, around Kubernetes, observability and developer tooling.

**Projects I help maintain**

- [kovetskiy/mark](https://github.com/kovetskiy/mark): sync your Markdown files with Confluence pages
- [Kube-State-Metrics](https://github.com/kubernetes/kube-state-metrics): Kubernetes object state as Prometheus metrics
- [Kube-Router](https://github.com/cloudnativelabs/kube-router): Kubernetes networking with BGP routing, network policies and IPVS service proxy
- [Prometheus-Community/Helm-Charts](https://github.com/prometheus-community/helm-charts): Helm charts for Prometheus and its ecosystem
- [CoreDNS/Helm](https://github.com/coredns/helm): the Helm chart for CoreDNS

**Things I've built recently**

- [kube-crisp](https://github.com/mrueg/kube-crisp): serve any SQL database as Kubernetes custom resources through an aggregated API server
- [spillway](https://github.com/mrueg/spillway): serve CRDs and their objects out of a kcp workspace instead of your cluster's etcd
- [git-remote-oci](https://github.com/mrueg/git-remote-oci): store Git repositories in an OCI registry, no Git server required
- [goldmark-lint](https://github.com/mrueg/goldmark-lint): a Go port of markdownlint built on goldmark
- [kepler](https://github.com/mrueg/kepler): an explorer for Kubernetes Enhancement Proposals
- [netcupscp-exporter](https://github.com/mrueg/netcupscp-exporter): a Prometheus exporter for the Netcup Server Control Panel
- [external-dns-netcup-webhook](https://github.com/mrueg/external-dns-netcup-webhook): an ExternalDNS webhook provider to manage Netcup DNS records

Away from Kubernetes I tinker with Home Assistant and maintain a few add-ons, such as [addon-teddycloud](https://github.com/mrueg/addon-teddycloud).

From 2012 to 2020 I was a [Gentoo Linux](https://gentoo.org) developer and packaged a wide range of software. That taught me a lot about how software gets built and shipped, so many of my contributions elsewhere focus on quality, security and release engineering.

You can reach me on the Kubernetes Slack. My nick is the same as here.
